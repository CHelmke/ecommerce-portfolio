# GitHub Desktop Setup Guide

This portfolio is structured so the root README becomes the landing page recruiters see on GitHub.

## Repository name
`ecommerce-portfolio`

## Suggested description
`Ecommerce & marketplace operations portfolio: Amazon, Walmart, Shopify, catalog, forecasting, FBA inventory, PPC, account health and launch workflows.`

## Recommended visibility
Public, if the repository is being used as a job-application portfolio.

## Important
The repository should contain the CONTENTS of the `ecommerce-portfolio` folder at its root. Recruiters should immediately see `README.md`, the portfolio PDF and project folders 01-10 rather than another nested `ecommerce-portfolio` directory.
